SITE « LES SAVEURS DU SUD DE LA FRANCE »

Version prête pour GitHub Pages.

CONTENU
- index.html : page principale
- style.css : décoration et mise en page
- script.js : les 6 spécialités, descriptions et vidéos
- images/ : dossier prévu pour d'éventuelles images supplémentaires

SPÉCIALITÉS
1. Gardiane de taureau
2. Aïoli
3. Daube de sanglier
4. Picholine
5. Aligot
6. Tielle sétoise

IMPORTANT
Les illustrations des cartes utilisent automatiquement les miniatures YouTube des vidéos.
Les vidéos sont intégrées depuis YouTube : elles ne sont donc pas stockées dans le site.

POUR GITHUB PAGES
1. Décompresser ce ZIP.
2. Créer un dépôt GitHub public.
3. Envoyer index.html, style.css, script.js et le dossier images à la racine du dépôt.
4. Settings > Pages.
5. Source : Deploy from a branch.
6. Branch : main / root.
7. Save.
8. Après la publication, ouvrir l'URL affichée par GitHub Pages.

Le site est statique : aucun compte utilisateur, aucune base de données et aucun mot de passe ne sont nécessaires.

VIDÉOS
Les vidéos sont intégrées depuis YouTube et restent hébergées par leurs créateurs/éditeurs respectifs.


IMAGES
Les six images des cartes ont été extraites directement des deux diapositives fournies pour permettre aux camarades de reconnaître rapidement les spécialités.


PRÉSENTATION
Ce site est conçu pour accompagner une présentation scolaire sur des spécialités et produits régionaux du Sud de la France, notamment d’Occitanie. Il ne présente pas les spécialités de la région personnelle de l’élève.
